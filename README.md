# B站视频画面理解

用户分享 B站视频时，不下载完整视频，而是：

1. 解析 BV 号（支持 bilibili.com/video/BV... 和 b23.tv 短链）
2. 调用 B站公开接口取视频标题、简介、时长和**缩略图雪碧图**（默认 10x10 帧）
3. 抽 9 帧拼成带时间标签的 3x3 画面
4. 交给视觉模型描述画面内容（可在配置里指定，留空则用当前对话模型）
5. 返回给主模型，用她自己的口吻回应

限制：只能看画面+标题简介，看不到字幕细节；视频没有缩略图时只返回标题简介。

## 依赖

- 需要 Pillow（本插件 requirements.txt 已声明，AstrBot 安装插件时会自动装）。
- 需要一个能看图的模型：在配置 `vision_provider_id` 里填你的视觉模型 id；留空则回退到当前对话使用中的模型。
